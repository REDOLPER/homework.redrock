# Lv3呀

## 代码

``` javascript {.numberLines}
async function foo() {
  console.log("start");
  await bar();
  console.log("end");
}

async function bar() {
  console.log("bar");
}

console.log(1);

setTimeout(() => {
  console.log("time");
});

foo();

new Promise((resolve) => {
  console.log("p1");
  resolve();
}).then(() => {
  console.log("p2");
});

console.log(2);
```

## 输出结果

``` markdown
1
start
bar
p1
2
end
p2
time
```

## 分析

### 第1轮

- 定义 `foo()` 和 `bar()` 函数（不执行）
- 遇到 `console.log(1);` ，输出 1
- 遇到 `setTimeout` ，其回调函数被分发到宏任务Event Queue中
- 执行 `foo()` ，输出 start
- 遇到 `await bar()` ，输出 bar ，暂停 `foo()` 函数的执行，将 `console.log("end");` 的回调放入微任务Event Queue中
- 遇到 `new Promise` ，输出 p1 ，将 `then` 分发到微任务Event Queue中
- 遇到 `console.log(2);` ，输出 2

| 宏任务Event Queue | 微任务Event Queue |
| ----------------- | ----------------- |
| setTimeout        |console.log("end");|
|                   | then              |

此时输出为

``` markdown
1
start
bar
p1
2
```

开始清空微任务

- `console.log("end");` ，输出 end
- 遇到 `then` ，输出 p2

此时输出为

``` markdown
1
start
bar
p1
2
end
p2
```

### 第2轮

- 从宏任务 `setTimeout` 开始，输出 time
- 结束

全部输出为

``` markdown
1
start
bar
p1
2
end
p2
time
```
